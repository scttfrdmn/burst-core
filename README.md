# burst-core

AWS cloud bursting — Go CLI and shared backend for the [burst family](https://burst-core.dev).

## Installation

```bash
curl -fsSL https://burst-core.dev/install | sh
```

Or download a binary from the [releases page](https://github.com/scttfrdmn/burst-core/releases).

## Quick Start

```bash
burst-core setup
```

## Language Libraries

| Language | Library | Install |
|----------|---------|---------|
| Python | [adder](https://github.com/scttfrdmn/adder) | `pip install adder-burst` |
| TypeScript / Node.js | [stet](https://github.com/scttfrdmn/stet) | `npm install stet` |
| Julia | [Fatou.jl](https://github.com/scttfrdmn/Fatou.jl) | `Pkg.add(url="https://github.com/scttfrdmn/Fatou.jl")` |
| Go | [aji](https://github.com/scttfrdmn/burst-core/tree/main/aji) | `go get github.com/scttfrdmn/burst-core/aji` |
| R | [staRburst](https://github.com/scttfrdmn/staRburst) | `install.packages("staRburst")` |
| Rust | [ferro](https://github.com/scttfrdmn/ferro) | `cargo add ferro` |
